# CE5K Target Marks Tracker

Upload these files to a GitHub repository and enable GitHub Pages.

Files:
- index.html — main tracker
- manifest.json — installable web-app settings
- sw.js — offline cache
- icon.svg — app icon

Important:
- Target marks are GOALS, not input limits.
- Input limits are the official maximum marks for each component.
- ENDS is corrected to FA-PR 50 + SA-PR 25 = 75.
- The tracker calculates subject totals, overall score, percentage, target gap, and filled components automatically.
- Data is saved locally in the browser.
